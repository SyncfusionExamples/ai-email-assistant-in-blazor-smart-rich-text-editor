# AI Email Assistant in Blazor Smart Rich Text Editor
A quick-start project that demonstrates how to build an AI-powered Email Assistant using the Syncfusion Blazor Smart Rich Text Editor. This project includes examples of creating an email composition interface, configuring AI Assistant settings, defining custom AI commands, and enhancing email content with AI-powered assistance.

Refer to the following documentation to learn about the Blazor Smart Rich Text Editor component: 
https://help.syncfusion.com/rich-text-editor-sdk/blazor/smart-rich-text-editor/getting-started-webapp

Check out this online example of the Blazor Smart Rich Text Editor component:
https://blazor.syncfusion.com/demos/ai-smart-rich-text-editor/ai-email-assistant?theme=tailwind3

## Project prerequisites

- Visual Studio 2019 or later versions
- .NET Core SDK
- Basic understanding of Blazor application development
- AI service configuration 

## How to run this application
- To run this application, you need to first clone the `ai-email-assistant-in-blazor-smart-rich-text-editor` repository and then open it in Visual Studio 2022. 
- Configure AI service credentials 
- Build the project to ensure all dependencies are resolved
- To debug: Press F5 or select Debug > Start Debugging
- To run without debugging: Press Ctrl+F5 or select Debug > Start Without Debugging
